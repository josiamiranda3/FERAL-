# FERAL® — Architecture for the Living World

An original creative front-end concept for an independent architecture and landscape practice. FERAL takes a different direction from dark, sci-fi portfolio experiences: warm mineral colors, botanical forms, editorial typography, architectural imagery, and a procedural 3D sculpture that feels grown rather than manufactured.

## Experience

- Procedural Three.js sculpture with layered architectural arcs, organic geometry, leaves, floating pollen, lighting, and pointer-responsive camera movement.
- Light, tactile art direction built around warm paper, forest green, moss, and mineral neutrals.
- Large editorial typography and asymmetrical layouts.
- GSAP entrance animations and scroll-triggered reveals.
- Project detail overlays, full-screen navigation, and responsive interaction patterns.
- Responsive layouts and reduced-motion preference support.

## Stack

- React 18
- Vite 6
- Three.js
- GSAP + ScrollTrigger
- CSS
- Lucide React

## Run locally

Requires Node.js and npm.

```bash
npm install
npm run dev
```

Open the local URL shown by Vite (typically `http://localhost:5173/`).

## Production build

```bash
npm run build
npm run preview
```
